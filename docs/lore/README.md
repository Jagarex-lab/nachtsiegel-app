# ORAFOLD — Arbeits-Lore (NICHT KANON)
Stand: 2026-11-10. Alle neu eingeführten Namen, Figuren, Orte und Ereignisse sind **VORSCHLÄGE**. `docs/LORE-BIBLE.md` bleibt die Kanonreferenz. Keine Änderungen am Spiel.

**Kurzpitch:** Als die Retter einer Hungerkatastrophe eine bereits geschehene Entscheidung rückwirkend korrigierten, blieb die verhinderte Geschichte als zweite gültige Vergangenheit bestehen. Überlagerungszonen entstanden. Heute geraten vier weltumspannende Organisationen in Konflikt, als ein Netzwerk von Stabilisierungsknoten scheinbar gezielt Menschen aus den Registern löscht. Ein verschwundener Name – Eira – taucht auf unabhängigen Zeugnissen auf.

**Einordnung:** Die konkrete Hungerkatastrophe ist eines von drei konkurrierenden Ursprungsmodellen, nicht bereits die Wahrheit. Die Hauptgeschichte und die Figuren dürfen erst nach Entscheidung des Nutzers kanonisiert werden.
